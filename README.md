# Baritone Studio

Клиентский мод для **Minecraft 1.21.11** на **Fabric Loader 0.19.5** (нужен Fabric API 0.141.x).
Автопилот в духе Baritone, но настраиваемый: готовые **пресеты** (камень, дерево, руды, кирпич, урожай…),
свои пресеты и главное — **запись действий**: сделал что-то один раз (поставил табличку, написал на ней текст) —
мод повторит это в других местах, заранее показав предпросмотр.

Меню открывается клавишей **B** (меняется в самом меню или в «Настройки → Управление»).

## Установка

1. Установите Fabric Loader 0.19.5 для 1.21.11 и положите в `mods/` Fabric API.
2. Положите `baritone-studio-1.4.0.jar` (папка `dist/`, либо соберите сами) в `mods/`.
3. В игре нажмите **B**.

Сборка: `./gradlew build` → `build/libs/baritone-studio-1.4.0.jar` (нужна Java 21).

## Что умеет

### Пресеты (вкладка «Пресеты»)
Камень, дерево, кирпич, земля, песок/гравий, уголь, железо, медь, золото, редстоун, лазурит, алмазы, изумруды,
кварц, древние обломки, урожай (с пересадкой), тыквы/тростник, туннель вперёд, спуск на нужный уровень Y,
сбор выпавших предметов.
Для каждого можно задать, сколько добыть и радиус поиска. Кнопка «Копировать и изменить» / «Свой пресет» — собственный
набор блоков: `stone, #minecraft:logs, wheat[age=7]` (id, теги, свойства состояния).

Бот сам находит ближайший нужный блок, строит путь (ходьба, прыжки, спуски, прокапывание, столб из блоков вверх),
выбирает лучший инструмент, ломает, подбирает дроп и повторяет.

### Запись и повтор (вкладка «Запись»)
1. «Начать запись» (или клавиша **V**) → делайте что нужно: ломайте блоки, ставьте блоки, нажимайте кнопки/двери,
   пишите текст на табличках. Запись повторно остановить — **V** или в меню.
2. В списке выберите запись → «Выбрать места». Наведите прицел на блок, который соответствует **первому блоку записи**
   (тот, по которому вы кликнули/который сломали первым), и нажмите **Enter**. В мире сразу виден **предпросмотр**:
   красный — сломать, зелёный — поставить, синий — клик, жёлтый — надпись, голубой — путь, оранжевый — место занято.
   **R** — повернуть на 90°, **Backspace** — убрать последнее место, **B** — вернуться в меню.
   Поворот по умолчанию берётся из того, куда вы смотрите.
3. «Серия» добавляет N копий с шагом (dX, dY, dZ) — удобно для рядов табличек.
4. «Повторить» — бот пройдёт по всем местам и выполнит все шаги.

Тексты табличек можно править на вкладке «Таблички». `{n}` в тексте заменяется номером повтора
(`Дом {n}` → «Дом 1», «Дом 2», …); старт и шаг нумерации задаются там же.
Если нужного предмета нет в инвентаре, бот ждёт его (время ожидания — в настройках) и не ломает постройки по дороге.

Записи лежат в `config/baritonestudio/macros/*.json`, пресеты — в `config/baritonestudio/presets.json`,
настройки — в `config/baritonestudio/config.json`.

### Клавиши (все меняются)
| Действие | По умолчанию |
|---|---|
| Открыть меню | **B** |
| Остановить всё | N |
| Начать/закончить запись | V |
| Выбор мест: добавить / повернуть / убрать | Enter / R / Backspace |

Команды: `/bs stop`, `/bs goto x y z`, `/bs preset <id>`, `/bs record`, `/bs run`, `/bs follow [ник]`, `/bs explore`, `/bs surface`, `/bs wp set|goto|del|list`.

## Новое в 1.1

**Настройки → Поведение**
* **Обходить воду / обходить лаву** — по умолчанию включено (отдельные переключатели; лаву выключать опасно).
* **Только видимые руды (legitMine)**, **автоеда**, список блоков «никогда не ломать по пути».

**Human-Mode** (Настройки → Human-Mode, ползунок силы): плавная мышь с замедлением к цели, лёгким дрожанием и шагами,
кратными чувствительности мыши; паузы на ходу, непостоянный бег, разная задержка прыжка; реакция на новый блок не мгновенно,
разные точки прицеливания в блоке, редкие «заминки»; при строительстве — разные точки клика по грани и неравные паузы между действиями.

**Выйти, пока не увидели** (Настройки): когда другой игрок подходит ближе заданной дистанции (по умолчанию 69 = 64 блока
видимости ника + запас 5), бот останавливает работу и выходит с сервера (или только останавливается). Есть список друзей
и режим «следить, только пока бот работает». Клиент видит игроков лишь в пределах дальности прорисовки сервера.

**Из Baritone** (вкладка «Навигация» и команды `/bs`):
* `follow` — следовать за игроком по нику или за существом (`pig`), без аргумента — за ближайшим игроком;
* `explore` — исследование новых чанков; `surface` — выйти на поверхность;
* метки (`wp`): сохранить/идти/удалить, `/bs wp set|goto|del|list`;
* область: выделить два угла и **очистить** (сверху вниз) или **заполнить** выбранным блоком;
* legitMine, автоеда.
Не вошло: парkour, `build` по схемам, `farm` по области (есть пресет «Урожай»), обход мобов.

## Улучшения навигации и подбора (1.2)

* **Не блуждает**: из нескольких ближайших целей бот одним поиском выбирает ту, к которой *путь* короче, и держится её;
  встроены детектор «хождения по кругу», контроль прогресса и быстрый отказ, если цель недостижима
  (раньше можно было часами топтаться, например при воде на пути).
* **Столб больше не из дерева**: для опоры берутся дешёвые блоки (земля, булыжник, камень…), никогда не брёвна/доски и
  не то, что задача добывает; собственные опоры не считаются целями (баг «поставил дерево и сам же рубит»).
* **Подбор предметов**: рядом идёт на предмет напрямую, как игрок, и всегда подходит вплотную; ждёт появления дропа
  с учётом пинга; повтор записи тоже подбирает то, что выпало при ломании.
* **Human-Mode** стал заметнее похож на человека: оглядывается при остановках, «виляет» вбок, замедляется перед поворотом,
  «думает» перед началом пути и между блоками, меняет инструмент не мгновенно.

## Human-Mode: ваш почерк на деревьях (1.4)

Настройки → Human-Mode → «Обучение: срубить 10 деревьев» (или `/bs learn`). Дальше рубите деревья **сами, как обычно**.
Пока идёт обучение, мод записывает для каждого дерева отдельный профиль вашего почерка:
* как вы наводите мышь на бревно: кривая скорости поворота (разгон, торможение, перелёт) и средняя скорость;
* время от наведения до первого удара, паузы между брёвнами;
* дистанцию, с которой бьёте, и точку в бревне, куда целитесь (со статистическим разбросом);
* дрожание прицела при ударах и как часто сначала смотрите вверх на крону.

После 10 деревьев обучение заканчивается само. Включите Human-Mode и переключатель «Рубить деревья вашим почерком»:
для каждого нового дерева бот случайно берёт один из записанных профилей (два последних не повторяются) и рубит
им: подходит на вашу дистанцию удара, наводит мышь по вашей кривой с вашим дрожанием, выдерживает ваши паузы.
Работает только для брёвен; остальное — обычный Human-Mode. Профили хранятся в `config/baritonestudio/human_profiles.json`
и остаются у вас на компьютере.

## Движение (1.3)

Алгоритм поиска пути переписан по мотивам Baritone (идеи и константы; код написан заново, лицензия Baritone — LGPL):
* **Стоимость в тиках**: ходьба 4.63, спринт 3.56, падение по физике игрока, прыжок, плавание, лестницы;
  реальное время ломания блока лучшим инструментом из инвентаря (твёрдую стену бот обходит, тонкую — прокапывает).
* **A\* с несколькими «лучшими частичными» путями** и двумя таймаутами; при упоре в незагруженные чанки сразу отдаёт
  частичный путь; поиск идёт кусочками по тикам (игра не подвисает).
* **Сшивка путей**: пока бот идёт по частичному пути, следующий отрезок уже считается — без остановок на стыках.
* **Штраф за возврат** по пройденному маршруту (бот не мечется между равноценными путями).
* **Новые ходы**: прыжки через пропасти 1–3 блока (parkour, включается в настройках), лестницы и лоза, ступеньки с разбегом.
* **Исполнитель**: пороги отклонения как в Baritone (>3 блоков сразу, >2 дольше 10 секунд), возврат к узлу после отбрасывания,
  ожидание подгрузки чанка, таймаут хода, торможение перед поворотом и целью.

## Безопасность и ограничения

* Мод только клиентский. Он автоматизирует ввод игрока; на многих серверах это запрещено — пользуйтесь там,
  где разрешено правилами.
* Остановка при смерти, при низком здоровье (настраивается), при полном инвентаре; путь не ведёт в лаву
  и не ломает блок рядом с лавой, не ломает сундуки/спавнеры.
* Запись сейчас охватывает блоки: ломание, установка/клик по блоку, текст табличек. Инвентари (перекладывание
  предметов), бой и чат не записываются.
* Повтор записи никогда не ломает блоки «по пути» — только то, что записано.

## Проверка

`./gradlew runClientGameTest` (нужен дисплей, например `xvfb-run`) запускает настоящий клиент Minecraft и проходит
сквозной сценарий: ходьба с прыжками, добыча камня и руды, рубка дерева со столбом, запись «поставить табличку и
сломать блок» и повтор в четырёх местах (один с поворотом) с проверкой текста на табличках.
